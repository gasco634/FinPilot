# Portrait de connexion

La page de connexion charge `/assets/jeremie.webp` avec `loading="lazy"` et un repli accessible sur les initiales « JG ».

Déposez ici un portrait validé de Jérémie au format WebP, nommé `jeremie.webp`, et compressé à 80 Ko maximum. Aucun portrait personnel n’étant présent dans le projet, aucun visage de substitution n’est fourni.
